- حالة الخطأ: حافة `danger` وسطر خطأ بلون `danger` مع أيقونة ✕ وجملة تقول ما المطلوب، لا «خطأ» وحدها.
- التركيز: حلقة 2px بلون `focus` وحافة `brand`.
- الأرقام (كمية، سعر) تكتب بأرقام لاتينية 0-9 ويُضبط اتجاه الحقل `ltr` مع محاذاة النهاية.
