# هوية طلبية البصرية — تعليمات لـ Claude Code

اقرأ `README.md` أولًا (دليل الهوية)، ثم استخدم:
- `tokens.css`: متغيرات CSS جاهزة (فاتح الافتراضي، و`[data-theme="dark"]` للداكن).
- `tokens.json`: الرموز كبيانات (ألوان، خطوط، مسافات، زوايا، ظل) لتحويلها إلى ResourceDictionary في WPF أو غيره.
- `assets/Logos/`: الشعار العمودي والأفقي وأيقونة الحافظة (صور نقطية بأرضية بيضاء).
- `components/`: أصناف `tl-*` في `bundle.css` وملفات `preview.html` كمرجع لشكل الأزرار والشارات والحقول وصف الطلبية.

القواعد: الواجهة عربية RTL، الأرقام لاتينية 0-9، لا تستخدم `green` للنص (استخدم `green-strong`)، وكل حالة تحمل أيقونة وكلمة وليس لونًا وحده.
